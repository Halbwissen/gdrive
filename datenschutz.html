Datenschutzerklärung

Die Google-OAuth-App "rclone" wird nur vom Betreiber selbst genutzt, um mit dem Programm rclone auf das eigene Google Drive zuzugreifen. Dabei werden Dateien nur auf dem eigenen Computer eingebunden. Es werden keine Daten auf Servern des Betreibers gespeichert, verkauft oder an Dritte weitergegeben. Zugriffstoken liegen ausschließlich lokal auf dem eigenen Computer. Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions widerrufen. Kontakt: über mein GitHub-Profil.

Privacy policy

The Google OAuth app "rclone" is used only by its owner to access the owner's own Google Drive with the rclone program. Files are only mounted on the owner's own computer. No data is stored on the operator's servers, sold or shared with third parties. Access tokens are stored locally on the owner's computer only. Access can be revoked at any time at myaccount.google.com/permissions. Contact: via the GitHub profile of this page.

The use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.
